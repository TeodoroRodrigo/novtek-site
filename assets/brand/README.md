# Novtek Designer Assets

Normalized filenames from the designer delivery.

- `novtek-wordmark-color.svg`: primary color wordmark.
- `novtek-wordmark-color-large.svg`: high-resolution color wordmark export.
- `novtek-wordmark-white.svg`: white wordmark for orange/dark backgrounds.
- `novtek-wordmark-orange.svg`: single-color orange wordmark.
- `novtek-wordmark-graphite.svg`: single-color graphite wordmark.
- `novtek-symbol-white.svg`: white standalone N symbol.
- `novtek-symbol-orange.svg`: orange standalone N symbol and favicon source.
- `novtek-symbol-graphite.svg`: graphite standalone N symbol.
- `profile-logo-*.png`: square social/profile logo exports.
- `profile-symbol-*.png`: square social/profile symbol exports.
- `novtek-logo.pdf`: designer PDF logo guide/export.
- `novtek-logo-print.pdf`: print-production logo PDF from the designer delivery.
- `novtek-logo-source.ai`: Illustrator source file.
