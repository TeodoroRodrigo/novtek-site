# Novtek Site

Static institutional site for Novtek.

Novtek direction:

- Brand: Novtek
- Tagline: Solutions and Services
- Positioning: innovative and modern with a corporate, executive tone
- Focus: investments, assets, and business
- Languages: PT-BR and English
- Logo asset: `assets/novtek-wordmark-logo-v1.svg`

Run locally:

```sh
python3 -m http.server 4174
```

Then open:

```text
http://localhost:4174
```
